BlackTelperion.io.enmap module

Load EnMAP hyperspectral data as a BlackImage.

EnMAP L2A products are distributed as a directory containing a BSQ spectral image with an ENVI .HDR sidecar and a -METADATA.XML file that holds per-band wavelengths, FWHM, and quality metadata.

The image is loaded as raw int16 so that the existing BlackData.decompress() workflow can be used to convert to float32 reflectance.

Typical usage:

from BlackTelperion.io.enmap import loadEnMAP
image = loadEnMAP("/path/to/ENMAP01-____L2A-.../")
image.decompress()   # → float32 reflectance with NaN nodata
BlackTelperion.io.enmap.is_enmap_product(path)[source]

Return True if path (a directory) looks like an EnMAP product.

Detection is based on the presence of a *-SPECTRAL_IMAGE.BSQ file somewhere under path.

BlackTelperion.io.enmap.loadEnMAP(path)[source]

Load an EnMAP L2A product into a BlackImage with int16 data.

The returned image keeps the raw integer values. Use image.decompress() to apply the reflectance scale factor and mask nodata pixels.

Parameters:

path (str) – path to the EnMAP product directory (outer or inner).

Returns:

224-band hyperspectral cube (int16) with wavelengths, FWHM, georeferencing, and reflectance scale factor = 10000 populated in the header.

Return type:

BlackImage

Raises:

FileNotFoundError – if required product files are missing.

Example:

img = loadEnMAP("/data/ENMAP01-____L2A-DT.../")
img.decompress()          # convert to float32 reflectance
img.quick_plot(bands=(50, 30, 10))
